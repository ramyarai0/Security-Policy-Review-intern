# APPENDIX A – DETAILED ACTION CHECKLIST

This checklist is intended for use during an actual organizational security policy review. It provides a practical way to assign ownership, identify required evidence and record the status of each verification activity. Since this Week 3 review is based on a hypothetical organization, the status of each item is initially marked as “Pending Verification”. During an actual review, these statuses should be replaced with evidence-based results after checking the relevant organizational records and systems.

| No. | Action | Evidence | Owner | Frequency | Status/Result |
| --- | --- | --- | --- | --- | --- |
| 1 | Verify MFA coverage for all high-risk services. | MFA/identity report | IT/Security | Quarterly | Pending Verification |
| 2 | Review privileged and sensitive accounts and remove unnecessary access. | Access-review record | System Owners | Quarterly | Pending Verification |
| 3 | Verify recently offboarded users are disabled. | Offboarding/account records | HR + IT | Each exit | Pending Verification |
| 4 | Check critical patches against defined remediation SLA. | Patch report | IT | Monthly | Pending Verification |
| 5 | Verify endpoint security coverage. | Endpoint/EDR report | IT/Security | Monthly | Pending Verification |
| 6 | Sample sensitive data and verify classification/handling. | Sample files/storage controls | Data Owner | Quarterly | Pending Verification |
| 7 | Run an incident-reporting exercise. | Exercise/ticket record | Security Team | Semi-annually | Pending Verification |
| 8 | Perform a controlled backup restoration test. | Restore-test report | IT | Quarterly | Pending Verification |
| 9 | Review employee security-training completion. | Training report | HR/Security | Quarterly | Pending Verification |
| 10 | Review overdue vulnerabilities and remediation owners. | Vulnerability report | Security Team | Monthly | Pending Verification |
| 11 | Review vendor accounts and approvals. | Vendor-access register | System Owners | Quarterly | Pending Verification |
| 12 | Verify remote access uses approved methods and MFA. | VPN/access records | IT/Security | Quarterly | Pending Verification |
| 13 | Check policy owner, version and next review date. | Policy register | Policy Owner | Annual | Pending Verification |
