# Security Policy Review

## Week 3 – Security Policy Review

This repository contains my Week 3 internship work on **Security Policy Review**.

During Week 3 of my internship, I conducted a review of a hypothetical organization's security policy and identified areas where general requirements needed to be converted into specific and measurable security actions.

## Objective

The objective of this task was to review a hypothetical organization's security policy, identify security gaps and associated risks, and recommend practical improvements.

## Repository Contents

- `report/` – Complete Week 3 Security Policy Review DOCX report
- `sections/` – Sections 1–16 of the report
- `references/` – Section 17: References
- `appendices/` – Appendices A–C

## Review Areas

The policy review covered access control, authentication and MFA, password management, data protection, endpoint security, incident response, backup and recovery, security awareness, vulnerability management, third-party security, remote access and policy governance.

## Main Deliverables

The report includes:

- Research and methodology
- Security policy review
- Security policy review checklist
- Identified security gaps
- Risk assessment
- Recommended policy improvements
- Policy validation
- Implementation roadmap
- Roles and responsibilities
- Challenges faced
- Learning outcomes
- Conclusion
- References
- Detailed action checklist
- Risk register
- Suggested security policy structure

## Validation

The review includes policy walkthroughs and hypothetical security scenarios. No live production systems or organizational security infrastructure were tested.

## Note

This Week 3 review is based on a hypothetical organization. The detailed action checklist states that, during an actual review, “Pending Verification” statuses should be replaced with evidence-based results after checking the relevant organizational records and systems.
