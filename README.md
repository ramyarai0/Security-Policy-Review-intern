# Security Policy Review

## Week 3 – Security Policy Review

### Overview

This repository contains the work completed for Week 3 of the internship on **Security Policy Review**.

The project focuses on reviewing the security policy of a hypothetical medium-sized organization and identifying areas where the existing policy can be improved. The review covers important cybersecurity areas such as access control, authentication and MFA, data protection, endpoint security, incident response, backup and recovery, security awareness, vulnerability management, third-party security, remote access, and policy governance.

The identified gaps are converted into specific and measurable security improvement actions, supported by risk assessment, validation scenarios, an implementation roadmap, and action checklists.

---

## Objective

The main objectives of this security policy review are to:

- Understand the purpose and structure of an organizational security policy.
- Review a hypothetical organization's security policy against common cybersecurity control areas.
- Identify missing, unclear, or weak security policy requirements.
- Convert identified gaps into practical and measurable improvement actions.
- Assess the likelihood and impact of identified security risks.
- Prepare an action-oriented security policy review checklist.
- Validate the proposed improvements using hypothetical security scenarios and control checks.
- Prepare an implementation roadmap for the recommended improvements.
- Assign responsibilities to relevant organizational roles.
- Document the complete security policy review in a structured report.

---

## Review Areas

The security policy review covers the following control areas:

- Access Control and Least Privilege
- Authentication and Multi-Factor Authentication (MFA)
- Password Management
- Data Protection and Classification
- Endpoint Security and Patch Management
- Incident Response
- Backup and Recovery
- Security Awareness
- Vulnerability Management
- Third-Party Security
- Remote Access
- Policy Governance and Review
