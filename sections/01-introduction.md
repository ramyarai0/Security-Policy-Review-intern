# 1. INTRODUCTION

A security policy provides an organization with documented rules and responsibilities for protecting information, systems, applications, devices, and users. A policy is more effective when it is specific enough to guide real actions, assign responsibilities, define review frequency, and explain how compliance can be checked.

During Week 3 of my internship, I reviewed a hypothetical organization's security policy. The review focused on major security areas including access control, authentication, data protection, endpoint security, incident response, backup and recovery, security awareness, vulnerability management, remote access, and third-party security.

The main purpose of this review was to identify gaps or unclear requirements in the existing security policy and recommend practical improvements. The review also considered how the recommended controls could be verified using specific actions, supporting evidence, and scenario-based validation. The outcome of the review was a structured set of security recommendations, risk priorities, an action-oriented checklist, and an implementation roadmap for improving the organization's overall security posture.
