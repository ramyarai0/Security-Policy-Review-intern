# 7. SECURITY POLICY REVIEW CHECKLIST

This checklist was developed to make the security policy review more specific and measurable. Each item identifies a verification action, the evidence required, and the appropriate frequency or trigger for review.

| Control Area | Specific Verification Action | Evidence to Check | Frequency/Trigger | Status |
| --- | --- | --- | --- | --- |
| MFA | Verify MFA is enabled for email, cloud, VPN and administrator accounts; identify exceptions. | Identity-provider/MFA reports; exception approvals | Quarterly | Pending verification |
| Access Review | Export privileged and sensitive accounts, obtain owner approval and remove unnecessary access. | Access-review record and approval log | Quarterly | Pending verification |
| Offboarding | Select recently exited users and verify accounts were disabled according to the defined process. | HR/IT offboarding record and account status | Each exit | Pending verification |
| Patch Management | Review critical systems and confirm security patches meet defined remediation timelines. | Patch dashboard/change records | Monthly | Pending verification |
| Endpoint Protection | Check whether organizational endpoints have active centrally managed protection. | Endpoint/EDR console report | Monthly | Pending verification |
| Data Classification | Select sample files and verify classification and handling rules are applied. | Sample documents and storage settings | Quarterly | Pending verification |
| Incident Reporting | Run a test reporting exercise and confirm the report reaches the designated contact. | Exercise record/ticket/email evidence | Semi-annually | Pending verification |
| Backup Recovery | Select a critical backup and perform a controlled restore test; record success/failure and recovery time. | Restore-test report | Quarterly | Pending verification |
| Security Awareness | Check onboarding and refresher-training completion and review results of awareness exercises. | Training records/results | Quarterly | Pending verification |
| Vulnerability Management | Review open vulnerabilities, severity, owner, remediation deadline and overdue items. | Vulnerability-management report | Monthly | Pending verification |
| Vendor Access | Review active vendor accounts and confirm business need and approval. | Vendor-access register | Quarterly | Pending verification |
| Remote Access | Check that remote access uses approved methods and MFA and that inactive access is removed. | VPN/access logs and configuration | Quarterly | Pending verification |
| Policy Governance | Check version, owner, approval date and next review date. | Policy register/version history | Annual/after major change | Pending verification |
