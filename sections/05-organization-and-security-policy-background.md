# 5. ORGANIZATION AND SECURITY POLICY BACKGROUND

### 5.1 Hypothetical Organization

For this review, the organization is assumed to be a medium-sized company with approximately 150 employees. It uses cloud services, employee laptops, email, web applications, internal networking, and third-party service providers. Some employees also work remotely.

### 5.2 Assumed Existing Policy

The assumed policy contains general requirements to protect company information, use authorized systems, maintain passwords securely, and report suspicious activity. However, several requirements do not specify exact actions, responsible personnel, deadlines, evidence requirements, or review frequency.

### 5.3 Policy Review Criteria

The policy was reviewed using the following criteria to determine whether its requirements were clear, practical, measurable, and suitable for ongoing security monitoring.

| Criterion | Question Used During Review |
| --- | --- |
| Specificity | Does the policy clearly state what must be done? |
| Responsibility | Does it identify who is responsible for implementing or monitoring the requirement? |
| Frequency/Timeline | Does it define when or how often the action should occur? |
| Evidence | Can compliance be demonstrated using records, reports, logs, or other system evidence? |
| Exception Handling | Does it explain how exceptions are requested, approved, documented, and reviewed? |
| Review | Does it define when the policy or control should be reassessed and updated? |
